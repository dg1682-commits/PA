# 🎬 Prompt Studio (콘텐츠 프롬프트 & 대본 저장소)

콘텐츠 기획 및 제작에 필요한 **대본, 이미지 프롬프트, 영상 생성 프롬프트, 비고 메모**를 체계적으로 저장하고 관리할 수 있는 웹 애플리케이션입니다.  
**Firebase Firestore 클라우드**와 실시간으로 연동되어 어떤 PC나 기기에서 접속하더라도 데이터가 자동 동기화되며, 오프라인 환경에서도 로컬 캐시를 통해 안전하게 유지됩니다.

---

## ✨ 주요 기능 및 특징

### 1. ☁️ Firebase Firestore 클라우드 실시간 연동
- **프로젝트 ID**: `promptsave-10211`
- 브라우저를 새로고침하거나 다른 컴퓨터에서 접속해도 모든 콘텐츠와 설정이 실시간으로 동기화됩니다.
- 오프라인 또는 인터넷 연결이 불안정할 때도 **로컬 캐시(LocalStorage & IndexedDB)**를 통해 작업이 중단되지 않습니다.
- **[설정] 탭**에서 클라우드 연동 상태 확인, 수동 일괄 동기화 및 강제 새로고침 기능 제공.

### 2. 🔗 왼쪽 사이드바: 필수 제작 도구 바로가기 (새 탭 연결)
메뉴와 참고 프롬프트 버튼 사이의 공간에 자주 사용하는 외부 제작 도구 5종 바로가기 링크를 배치했습니다:
- **FLOW** (`https://flow.google.com/`) - Google Flow 영상 생성
- **타입캐스트 (TTS)** (`https://studio.typecast.ai/...`) - AI 보이스/더빙
- **모션엘리먼츠** (`https://www.motionelements.com/ko/`) - 영상 스톡 및 템플릿
- **어도비 익스프레스** (`https://express.adobe.com/`) - 썸네일 및 디자인 편집
- **SUNO AI** (`https://suno.com/create...`) - AI 음악 및 BGM 생성

### 3. 💡 왼쪽 사이드바 상시 위치: 참고 프롬프트 6종 모음 (가독성 최적화)
- 사이드바 하단에 아담하고 단정하게 고정된 **[참고 프롬프트]** 퀵 버튼
- 텍스트 크기와 행간을 컴팩트하게 다듬어 긴 프롬프트도 부담 없이 스크롤하며 읽을 수 있는 2단 모달:
  1. `01 주제 프롬프트(비츠온TV용)`: 조명·전기·산업자재·MRO 유튜브 주제 발굴
  2. `02 대본 프롬프트(비츠온TV용)`: 2~3분 완성형 유튜브 내레이션 대본 작성
  3. `03 첫번째 프롬프트`: 대본 분석 및 3~4초 장면 분할 3D 키프레임 생성
  4. `04 두번째 Flow 프롬프트`: 개별 원본 이미지 인포그래픽 강화 편집
  5. `05 세번째 프롬프트(비츠온TV용)`: Google Flow 8초 영상 생성 프롬프트 마스터
  6. `06 파일 이름 정렬 프롬프트`: 스크립트 순서 기반 01, 02 순차 번호 파일명 정렬
- **원클릭 복사 버튼**: 선택된 프롬프트를 한 번의 클릭으로 클립보드에 복사

### 4. 📋 전용 리스트(테이블) 뷰 & 마크다운 내보내기 & 안전 삭제
- 한눈에 파악하기 편한 **정갈하고 시원한 테이블 리스트 구조**
- 제목, 채널명, 영상 형식(롱폼/쇼츠), 콘텐츠 유형, 포함 요소(대본·이미지·영상·비고 유무 뱃지), 수정일자 제공
- **관리 액션 버튼**:
  - 👁️ **상세보기**: 팝업으로 전체 대본/프롬프트 열람
  - ✏️ **수정하기**: 편집기 탭으로 즉시 이동
  - 📄 **MD 내보내기**: `[채널명][형식]_제목.md` 포맷으로 개별 콘텐츠를 마크다운 파일로 즉시 다운로드
  - 🗑️ **삭제하기**: 전용 경고 모달 팝업으로 실수 없는 안전 삭제 지원

### 5. 📊 컴팩트 & 슬림 데이터 대시보드
- 한 화면에 쏙 들어오는 **슬림형 KPI 지표 카드** (총 콘텐츠, 롱폼 수, 쇼츠 수, 광고 수)
- 아담하고 직관적인 크기의 **Chart.js 시각화 차트 (175px 높이)**:
  - 채널별 콘텐츠 도넛 차트
  - 영상 형식 바 차트 (롱폼 vs 쇼츠)
  - 콘텐츠 유형 파이 차트 (비츠온 콘텐츠 vs 광고)
  - 월별 생성 추이 라인 차트

### 6. ⚙️ 유연한 분류 및 항목 설정
- 설정 탭에서 채널명, 영상 형식, 콘텐츠 유형을 마우스 클릭만으로 자유롭게 추가 및 삭제 가능
- 추가한 항목은 클라우드 및 폼/검색 필터에 실시간 자동 반영

## 🔒 Firebase Firestore 보안 규칙(Rules) 설정 가이드

데이터가 원활하게 저장 및 실시간 동기화되려면 **Firebase 콘솔**에서 Firestore 데이터베이스 및 보안 규칙을 활성화해야 합니다:

1. [Firebase 콘솔](https://console.firebase.google.com/) 접속 -> `promptsave-10211` 프로젝트 선택
2. 좌측 메뉴에서 **[Firestore Database]** 클릭
   *(아직 데이터베이스가 없다면 [데이터베이스 만들기]를 누르고 기본 위치 `asia-northeast3(서울)` 선택)*
3. **[규칙(Rules)]** 탭으로 이동하여 아래 내용을 붙여넣고 **[게시(Publish)]**를 클릭합니다:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

1. 다운로드된 폴더(`프롬프트 저장소`)로 이동합니다.

3. 좌측 하단에 `🟢 Firebase 클라우드 연동됨` 표시가 뜨면 정상적으로 클라우드에 연결된 것입니다!
